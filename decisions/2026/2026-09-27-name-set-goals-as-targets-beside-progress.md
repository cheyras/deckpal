## 2026-09-27 — Name set goals as targets beside progress
**Decided by:** Chey (via Codex)

**Decision:** Put the goal selector beside the set progress count and name its three display choices Standard set, Master set, and Grandmaster set. Preserve the stored and URL value `complete` for Standard set.

**Why:** A badge reading COMPLETE beside “0 / 307 Collected” looked like a finished status, while the separate star that changed goals gave no clue that it controlled the count. The new names describe targets and the adjacent control shows where to change them.

**Implications:** Goal display copy in set progress, list rules, purchase preferences, and the landing page uses the same target names. Existing links and saved rules continue to resolve through their unchanged values. Deck-E points to the selector in the progress header.
