## 2026-10-10 — Deck-E starts every request on Claude Haiku 5.5, which names the job; code picks the model, a pathway guides the work, and a card asks what only the reader knows
**Decided by:** @cheyras (direction, tier name, consent rule, eval budget, triage on every message); built by Claude Opus 5.5 directing Codex workers.

**Decision:** Every new message is triaged by Claude Haiku 5.5 (`decke/triage.ts`: one forced `triage` tool, thinking off, 2.5 s, a deterministic heuristic on any failure), which names the request's pathway (`decke/pathways/names.ts`: battle_log, battle_review, deck_build, deck_iterate, collection_plan, lists, price_value, card_rules, research, navigate, small_talk, general) and its signals. Code, not the model, picks the tier (`decke/tiers.ts`): the pathway floor (Standard for deck_build, deck_iterate and battle_review; Quick for the rest), raised to Standard on a dissatisfied or correcting reader, a guard that fired last turn, two or more tool errors last turn, or a request for depth. Quick is Claude Haiku 5.5, Standard Claude Sonnet 5.5; Deep (Claude Opus 5.5) is named **Deep Think**, always offered with its cost on a card, and is wired in its own change. Effort is per tier (Quick: `low` for small talk and walking somewhere, `medium` for tool work; Standard `medium`), sent as a top-level Anthropic option with adaptive thinking. The system prompt is three blocks: a stable core (15.8k chars, was 29.6k; cached), the pathway's guidance (cached), and the date/route/landmarks (uncached); a cache breakpoint moves to the newest message each step. Deck-E can ask 1–4 multiple-choice questions on a docked card (`ask_user`); the answers return as the reader's next message. The corrective leg and the paste backstop run on Standard; a Quick turn that ends in a refusal with no text is retried once on Standard. This replaces the single-model part of the 2026-09-28 decision (Sonnet 5.5 for every request); the rest of that decision stands.

**Why:** The owner wants the everyday request to be cheap and the spend saved for requests that benefit, with Deck-E approaching each kind of job like someone who knows it (2026-10-10). Research (roadmap/plans/decke-harness-v2/PLAN.md §2): Claude Haiku 5.5 ties Sonnet 5.5 on bounded tool work (τ²-Airline 74.9% vs 74.7%, OpenRouter) but trails it on judgment (GDPval 1620 vs 1840; every task-measured comparison users published favoured Sonnet), so judgment-heavy pathways keep a Sonnet floor; small models fill rubrics reliably but grade their own competence poorly (Anthropic measured Haiku 5.5 consulting an Opus advisor on 0 of 198 questions), so code decides; Anthropic's Haiku 5.5 guide says a long system prompt at low effort "is more likely to skip a search, stop early, or skip a check", hence the slim core and per-job blocks; Haiku/Sonnet 5.5 distrust user words inside tool results, hence answers as a message. Measured on the replay probe (16 scenarios, fixture tools, 2026-10-10): routed 12/16 at $0.028 a scenario on the first run, Sonnet 5.5 alone (default effort) 10/14 at $0.049; Quick-tier jobs (prices, rules, lists, collection plans, navigation, small talk) cost $0.001–0.003 against $0.01–0.04; 56% of turns ran on Haiku. Two Haiku misses (logging an in-person game before asking; an undated meta answer) were fixed in the pathway text and pass 2/2 on re-run; the remaining "failures" were grader bugs, fixed. Gateway pass-through verified live: message cache reads on Haiku and Sonnet, Gateway cost on every call, thinking off and forced tool choice on Haiku.

**Implications:**
- `models.ts` `TIERS` and `PATHWAY_META` floors are the dials; move a pathway's floor with evidence from `scripts/decke-replay-probe.mjs --arms routed,<model>@<effort>`.
- Effort nested inside `thinking` is silently stripped by `@ai-sdk/anthropic`; `chatWiring.test.ts` pins the top-level shape.
- The 2026-08-21 objection to a router (a classifier tax on every message, invisible misroutes) is answered by a ~$0.0001, ~1 s Haiku call and one structured `[deck-e] route` log line per request (tier, pathways, effort, reasons, triage source, latency).
- Navigation guidance now lives in the navigate pathway; the core keeps a one-line-per-tool summary. Pathway texts are templates (goal, branches, definition of done, traps), not scripts.
- Haiku 5.5 bills a whole request at $0.50 / $2.50 per MTok once its prompt passes 100K tokens (vs $0.10 / $0.50 below); a long deck-building turn on Quick could cross it — those pathways start on Standard anyway.
- One route per turn, not per HTTP leg: the first leg streams a transient `data-decke-route` part and the browser sends it back as `tierRoute` on every continuation (approval, ask answer, browser tool), so a turn never changes model or pathway mid-way (`decke/routeEcho.ts`). The echo is unsigned by design — it can only choose Quick or Standard for the caller's own turn, on credits the caller pays at actual cost; `tier: 'deep'` is never a valid echo. A continuation with no valid echo is re-triaged with a Standard floor (`continuationFloor`).
- Triage's own Gateway spend is recorded under the advisory operation key `triage` (`runAdvisoryUsage`), separate from the turn's tool operations.
- `ask_user` ends the step: a step that asked the reader is final (`askedThisStep`), and no audit, paste backstop or corrective leg runs after it (`askedReader`) — the reader's answer is the next message.
- Pathway texts do not mention Deep Think until the change that wires it ships; asking for depth meanwhile gets the fuller treatment on Standard.
- Follow-ups in flight: Deep Think (consent card, larger credit hold, migration 083), battle logs v2 (in-person games, archetypes, analyses, migration 084), progress-update display and a consult tool.
