# DeckPal

Read `AGENTS.md` (repo root) first. It contains the engineering contracts,
verification standards, build commands, and doc/wiki-maintenance protocol
that apply to all contributors.

For a new decision, run `pnpm decisions new "Title"`, fill in the file under
`decisions/YYYY/`, and run `pnpm decisions:check`. The root `DECISIONS.md`
is a guide, not the append-only log.
