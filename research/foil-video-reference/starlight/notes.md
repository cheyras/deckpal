## Usage claim (per the video)

Base Set, Jungle, Fossil - international (non-Japanese) printings only; Japanese equivalents used Cosmos.

## Notes

One of the only true holograms in the TCG: front star layer moves side-to-side against the back layer (3D parallax). 'Galaxy' is an old name for this star foil (see cosmos notes).
