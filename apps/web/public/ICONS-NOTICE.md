# App icon provenance

The DeckPal app icons in this directory (`brand-icon.png`, `pwa-192.png`,
`pwa-512.png`, `pwa-maskable-192.png`, `pwa-maskable-512.png`,
`apple-touch-icon.png`, `favicon-32.png`, `favicon.ico`) are **original artwork**
created for this project on 2026-08-09: a fanned pair of generic trading cards
with a magnifying glass, rendered from the SVG sources kept alongside them
(`deckpal-icon.svg`, `deckpal-icon-maskable.svg`).

They are licensed with the repository (AGPL-3.0-only) and contain no third-party
imagery. They deliberately avoid any resemblance to Poké Balls, the Pokémon
wordmark/logotype, or other Nintendo / Creatures / GAME FREAK / The Pokémon
Company trademarks. This project is unofficial and is not affiliated with,
endorsed, or sponsored by those companies.

Regenerate the PNG set from the SVGs at the sizes above (the maskable variant is
full-bleed with the artwork inside the central 80% safe zone; `apple-touch-icon`
is rendered opaque). `favicon.ico` bundles 16/32/48 px renders.
